# 架构

公共入口只有 `gateways/whu`，注册 13 个 `whu_*` 工具。知网和国泰安位于 `connectors/`，按需加载为内部引擎，不再注册公共工具或 provider entry point。旧 `ADM_PROVIDERS=cnki,csmar,luojia` 迁移为 `whu`，已有 profile 保留。

`whu_search` 从珞珈实际 PNX 响应读取记录，结合页面真实链接生成访问路径。图书馆链接优先，不拼造代理 URL，不把其他平台的公开副本算作目标平台成功。

`whu_list_databases` 读取完整官网目录，缓存 15 分钟。`whu_get_database` 按唯一名称或 ID 获取详情及分页子库关系。详情请求必须带 `librarycode:131001`，并核对返回机构编号；其他机构详情返回 `metadata_scope_mismatch`。栏目类别、官方订阅状态、已购文字范围、账号权限、实际访问分别记录。子库关系即使属于武大也不直接推断为授权。

`whu_database_capabilities` 给出允许的库内操作及类型化参数；`whu_call_database` 校验参数后分派给知网/国泰安。没有任意模块或方法调用。国泰安导出只有显式调用才执行，能力表标明配额消耗。统一接口不意味着机构认证可替代每个平台要求的个人账号。

## 会话与失败

图书馆、中转和出版商使用 WHU profile；两个内部引擎各自保存会话，不互相复制凭据。WHU profile 有进程锁；旧 luojia 目录优先复用。专库会话是否能恢复由站点决定，认证窗口完成后仍需检查登录状态。

统一调用包含排队、浏览器启动、网络、解析的总时限。普通默认 30 秒、下载默认 60 秒。即使内部导出支持更长轮询，外层仍受总时限约束，可显式配置下载上限至 300 秒。超时、拒绝、待认证、验证页、解析错误分别报告，不当成零结果。

PDF 优先流式 HTTP 下载，同源失败时可用正常浏览器 fetch。检查文件大小、PDF 头、SHA256，不覆盖目标文件，失败清理临时文件。国泰安沿用站点的任务打包/下载流程。

## 扩展

新增专库优先放在 `connectors/<database>` 并显式加入 WHU 适配器允许列表；公共工具不随子库数增长。新增机构网关仍可通过 ProviderRuntime / ToolSpec 和 entry point 扩展。公开元数据、公开副本下载、机构授权下载必须分别记录。
